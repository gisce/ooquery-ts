### Títol: Fallo en el workflow de tests debido a ESM en Vite

#### Descripció:
El workflow de tests falla porque Vite se resuelve como un paquete ESM y no puede ser cargado con `require()`. El error que aparece en el log es el siguiente:
```
Error: Cannot find module 'vite'
```

#### Solució Proposada:
1. Sustituir `require('vite')` por `import`.
2. Asegurar que `vite.config.ts` sea ESM.
3. Configurar Node.js a >=16 en el workflow.
4. Actualizar Vite/Vitest.

#### Ejemplo de cambio:
Cambiar:
```javascript
const vite = require('vite');
```
A:
```javascript
import vite from 'vite';
```
